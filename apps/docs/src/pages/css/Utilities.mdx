# Additional utility classes

Bootstrap already comes with a bunch of [utility classes](https://getbootstrap.com/docs/6.0/utilities/background/).
Blue Web adds some additional to them.

## `.m-last-0:last-child`

Sets `margin: 0` to last child.
Useful for creating a gap between items together with `mb-5`.
Inspired by Tailwind CSS class `last:m-0`.

## `.blue-empty-message`

Shows empty message if the element has no children.
Can be used for lists and such.
For localization you should override CSS variable `--message` dynamically.

```html use:RenderBlock
<div class="blue-empty-message"></div>
```

## `.blue-contain-paint`

Fixing border radius clipping.

```html use:RenderBlock
<div class="border border-primary rounded-5 mb-5">
    <div class="bg-danger fg-contrast-danger p-5">Child background destroys border radius of parent. ☹️</div>
</div>
<div class="border border-primary rounded-5 blue-contain-paint">
    <div class="bg-success fg-contrast-success p-5">Much better! 🥳</div>
</div>
```

We automatically add it to Bootstrap's `.card`.

```html use:RenderBlock
<div class="card">
    <header class="card-header">My card</header>
    <div class="bg-success fg-contrast-success p-5"></div>
</div>
```

## `.blue-odd-bg`

Let you easily create striped items, like rows.

```html use:RenderBlock
<div class="blue-odd-bg">Item 1</div>
<div class="blue-odd-bg">Item 2</div>
<div class="blue-odd-bg">Item 3</div>
<div class="blue-odd-bg">Item 4</div>
```

You can set the background color using CSS variable `--blue-odd-bg`.

```html use:RenderBlock
<div style="--blue-odd-bg: cyan">
    <div class="blue-odd-bg">Item 1</div>
    <div class="blue-odd-bg">Item 2</div>
    <div class="blue-odd-bg">Item 3</div>
    <div class="blue-odd-bg">Item 4</div>
</div>
```
