# Modal

Bootstrap 6 [Dialogs](https://getbootstrap.com/docs/6.0/components/dialog/) use the native dialog element. Blue's `.blue-modal` hook remains available, without positioning/content wrappers or a separate backdrop form. Use `closedby="any"` for native backdrop dismissal in supporting browsers, or Bootstrap's `Dialog` JavaScript for its dismissal API.

```html use:RenderBlock
<button type="button" class="btn blue-btn-soft-primary" onclick="my_modal.showModal()">Open modal</button>

<dialog class="blue-modal dialog" id="my_modal" closedby="any">
    <div class="dialog-header">
        <h1 class="dialog-title fs-lg">Modal title</h1>
        <form method="dialog" style="display: contents;">
            <button type="submit" class="btn-close" aria-label="Close"></button>
        </form>
    </div>
    <div class="dialog-body">Hello World</div>
</dialog>
```

## Drawer

Bootstrap 6 [Drawers](https://getbootstrap.com/docs/6.0/components/drawer/) also use a native dialog, with `.drawer` and a placement class on that same element.

```html use:RenderBlock
<button type="button" class="btn blue-btn-soft-primary" onclick="my_drawer.showModal()">Open drawer</button>

<dialog class="blue-modal drawer drawer-start" id="my_drawer" aria-labelledby="drawerExampleLabel" closedby="any">
    <div class="drawer-header">
        <h5 class="drawer-title" id="drawerExampleLabel">Drawer</h5>
        <form method="dialog" style="display: contents;">
            <button type="submit" class="btn-close" aria-label="Close"></button>
        </form>
    </div>
    <div class="drawer-body">
        <div>
            Some text as placeholder. In real life you can have the elements you have chosen. Like, text, images, lists,
            etc.
        </div>
    </div>
</dialog>
```

## Show dialog in main DOM layer

If you use `dialog.showModal()`, the dialog will be inside the top layer, above anything else on your page, also if other elements have an higher `z-index`. Use `dialog.show()` instead and it will be inside the main layer.

```html use:RenderBlock
<button type="button" class="btn blue-btn-soft-primary" onclick="my_modal.show()">Open modal with .show()</button>
<button type="button" class="btn blue-btn-soft-primary" onclick="my_drawer.show()">
    Open drawer with .show()
</button>

<br />

<button type="button" class="btn blue-btn-soft-primary" onclick="my_modal.showModal()">
    Open modal with .showModal()
</button>
<button type="button" class="btn blue-btn-soft-primary" onclick="my_drawer.showModal()">
    Open drawer with .showModal()
</button>

<div class="border border-primary bg-body fg-body rounded p-5 mt-5 position-relative" style="z-index: 5000">
    This has a really high z-index. It should be over the dialog, when you open it with .show() and underneath it when
    you open it with .showModal().
</div>
```
