# ui-sdk

Before using ui-sdk:

- Follow the ui-sdk skill if it is installed.
- Read `node_modules/@ui-sdk/web/docs/llms.txt`.
- Import each component from its own entry, such as `@ui-sdk/web/dialog`, to register its custom-element tags.
- When building a new component, search `node_modules/@ui-sdk/web/docs/core.md` by heading and read `node_modules/@ui-sdk/web/docs/rendering.md`.
